# Nmap Network Reconnaissance Lab

## Project Overview

This project documents my practical learning and research using Nmap, a network discovery and security auditing tool.

## Learning Objectives

- Understand TCP and UDP ports.
- Discover hosts on authorised networks.
- Perform TCP SYN and TCP connect scans.
- Identify open, closed, and filtered ports.
- Detect running services and their versions.
- Understand basic operating system detection.
- Export and analyse scan results.
- Document security findings.

## Tools

- Kali Linux
- Nmap
- Linux Terminal

## Project Status

Currently learning and developing practical Nmap network reconnaissance skills.
